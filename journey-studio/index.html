Welcome to Alchemy Journey Studio

          
Design, document, and export Guidewire Jutro journeys with AI. Build screens, preview them in the Jutro FloorPlan shell, and generate developer-ready scaffold exports — all in one place.

          

            
            
            
          

        


        
        

          
How it works

          


            

              
1

              
🗺️

              
Build your journey

              
Describe a full flow in plain English. AI generates multiple named screens with fields, navigation links, and CTA buttons — or add screens manually.

              
Describe a journey in the AI Assist panel — no screen needs to be selected

            


            

              
2

              
🧩

              
Design PCF screens

              
Describe a screen's fields and AI populates the correct Guidewire widgets — TypeKeyInput, BooleanRadioInput, CurrencyInput and more — organised into panels.

              
Select a screen first, then describe its fields in the AI Assist panel

            


            

              
3

              
👁

              
Preview in Jutro

              
Click the Preview tab to see your screen rendered in the Guidewire Cloud Platform FloorPlan shell — with real field controls, panels, and navigation.

              
Click the Preview tab above the screen editor

            


            

              
4

              
📦

              
Export for developers

              
Download a Jutro scaffold ZIP containing metadata.json, a React component scaffold, and i18n messages — ready for a developer to drop straight into a project.

              
Click ↓ Export JSON → ↓ Dev Handoff Pack
