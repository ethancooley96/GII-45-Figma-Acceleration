# Alchemy Journey to Figma — Figma Plugin

## Milestone 1: Create an editable example journey screen

This plugin opens a small panel inside Figma. Clicking **"Create example screen"** programmatically builds a fully editable 1440 px desktop frame on a new page called **"Journey Studio / Test"**, containing:

- A page **header** (title + description)
- A **2-column form** with five fields (First name, Last name, Email, Telephone, Preferred contact method), each annotated with its Jutro component name
- A **button row** (secondary "Save and continue later" + primary "Continue")

All nodes are native Figma frames, rectangles and text — no external components or libraries required. Everything can be edited freely after creation.

## Project structure

```
figma-plugin/
├── manifest.json          # Figma plugin manifest
├── package.json           # npm scripts & dev dependencies
├── tsconfig.json          # TypeScript config (type-check only; esbuild bundles)
├── src/
│   ├── code.ts            # Plugin main thread (runs in Figma sandbox)
│   ├── ui.html            # Plugin UI panel (iframe)
│   └── html.d.ts          # TypeScript shim for *.html imports
└── dist/
    └── code.js            # Compiled output (generated by build)
```

## Setup

### Prerequisites

- [Node.js](https://nodejs.org/) 18 or later
- npm (bundled with Node.js)

### Install dependencies

```bash
cd figma-plugin
npm install
```

### Build once

```bash
npm run build
```

This bundles `src/code.ts` → `dist/code.js` using **esbuild** (no separate TypeScript compilation step needed for the output).

### Watch mode (re-builds on save)

```bash
npm run watch
```

---

## Loading the plugin in Figma

1. Open Figma Desktop.
2. Go to **Plugins → Development → Import plugin from manifest…**
3. Select `figma-plugin/manifest.json`.
4. Run the plugin from **Plugins → Development → Alchemy Journey to Figma**.

> **Note:** You must run `npm run build` at least once before loading the plugin so that `dist/code.js` exists.
